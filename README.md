# 인스타그램 영상 다운로더

인스타그램 게시물·릴스 링크를 붙여넣으면 영상을 mp4로 다운로드해주는 웹앱입니다. (Flask + yt-dlp)
구조는 `xx` 저장소(X 영상 다운로더)를 참고했습니다.

## 실행

```bash
pip install -r requirements.txt
python app.py          # http://127.0.0.1:5000
```

- `ffmpeg`가 설치되어 있으면 가장 안정적입니다.
- 동작이 갑자기 안 되면 인스타그램 쪽 변경 때문일 수 있으니 `pip install -U yt-dlp` 로 업데이트하세요.

## 환경 변수

| 이름 | 기본값 | 설명 |
| --- | --- | --- |
| `IG_COOKIES_FILE` | (없음) | 로그인이 필요한 게시물을 받을 때 쓸 쿠키 파일 경로 (Netscape 형식) |
| `HOST` | `127.0.0.1` | 접속을 허용할 주소. 외부에서 쓰려면 `0.0.0.0` |
| `PORT` | `5000` | 포트 번호 |

- 쿠키 파일은 본인 계정 정보이므로 다른 사람과 공유하거나 저장소에 올리지 마세요. `.gitignore`에 `cookies*.txt`가 포함되어 있습니다.
- 서버가 다운로드를 대신 요청하므로, 공개 서버에 올리면 누구나 쓸 수 있습니다. 개인 PC에서만 쓰는 것을 권장합니다.

## 제한 사항

- 사진 게시물은 지원하지 않습니다. 영상이 없는 항목은 목록에서 건너뜁니다.
- 스토리와 비공개 계정 게시물은 지원하지 않습니다.
- 여러 영상이 들어 있는 게시물(캐러셀)은 항목별로 따로 받을 수 있습니다.
